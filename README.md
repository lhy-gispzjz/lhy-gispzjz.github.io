# Homepage maintenance

This is a static GitHub Pages site. Edit `index.html` for text and links, and
`assets/site.css` for appearance. The profile photograph is `chuochuo2.jpg`.
No build step is required.

To preview locally from the repository folder:

```powershell
python -m http.server 8000
```

Open <http://localhost:8000/> and press Ctrl+C in PowerShell to stop the server.
Before publishing, run `git diff`, then commit and push to `main`.
